项目阶段性总结 2026.04
PROJECT REPORT · 阶段性汇报

01 / Background

从 Shopify 退守，到 WordPress 重建

公司旗下多个 Shopify 建站因产品性质相继被封，业务连续性面临挑战。在前期 WordPress 加班申请获批的基础上，本阶段的目标明确：在五一节点前交付一个能够独立承接欧洲市场流量、 且功能与体验全面对齐原 Shopify 站点的成熟版本，为旺季和世界杯流量做好准备。

02 / Performance Lift

速度，是最直接的体验。

采购并部署荷兰节点新服务器，将面向欧洲市场的网站迁移至新节点。 瑞典用户的页面加载时间发生了本阶段最具说服力的变化——

迁移前 / Before
6.3s
→ OPTIMIZED −54%
迁移后 / After
2.9s

6 秒以上的加载时间通常意味着用户大量流失，3 秒以内则进入"可用"区间。 这次迁移相当于把站点从「勉强可访问」直接拉到了「可以正常承接流量」的水平。

03 / Deliverables

结构化的交付清单。

本阶段工作分为四大类：基础设施、页面优化、组件接入与组件研发；另有 AI 能力建设作为独立亮点单列下一节。

A

基础设施 · Infrastructure

1 项
A1

服务器迁移与性能优化

采购部署荷兰节点新服务器，瑞典用户页面加载时间由 6.3 秒降至 2.9 秒，降幅约 54%。

B

页面优化 · Page Optimization

4 项
B1

主题选型与替换

经多轮评估与对比测试，选用性能更优、用户体验更佳的全新主题，作为后续所有页面优化与组件接入的基础底座。

B2

优化首页

更换首页页面模板，调整 Elementor 楼层产品列表排序与前 300 销量排序；统一页眉右侧图标风格、整站更换皮肤与主题色；移动端导航栏配置自动吸顶。

B3

优化购物车页面

系统性改造购物车页体验，移除 Elementor 自带侧边栏购物车；新增粘性购物车交互；调整在线客服窗口位置，提升下单链路通畅度。

B4

优化下单页面

结账页流程精简、字段优化、视觉统一；产品详情页缩略图单行展示、细节图横滑、隐藏冗余字段、本地化 CTA 文案 "Lägg i varukorg"、价格颜色统一为 #2DA764。

C

添加组件 · Component Integration

10 项
C1

购物车查看与挽回组件

记录用户购物车状态，并对接 EDM 挽回流程，对未完成下单用户自动触发邮件挽回，提升二次转化。

C2

尺码表组件

产品详情页可独立挂载尺码表，运营可在后台灵活配置不同品类的尺码对照信息。

C3

产品销量排名组件

展示热销产品排序，强化爆款引导，辅助提升用户决策效率与店铺销量集中度。

C4

悬浮视频组件

支持在页面任意位置嵌入悬浮视频播放，丰富内容呈现方式，提升落地页内容质量。

C5

产品组合组件

展示产品组合搭配方案，引导客单价提升，与下方研发的产品组合相关插件形成完整链路。

C6

支付组件

上线新支付插件并接入新增支付通道，扩充欧洲市场可用支付方式，降低弃单风险。

C7

在线客服组件

接入在线客服模块并优化展示位置，便于瑞典用户在购物过程中快速获得咨询响应。

C8

心愿单模块

用户可收藏感兴趣的产品至心愿单，提升二次访问与转化机会。

C9

产品详情页在线浏览人数

实时展示当前正在浏览该产品的用户数量，增强紧迫感与社交证明，促进下单决策。

C10

销售弹窗

实时弹窗展示近期成交订单信息，营造活跃下单氛围，增强用户信任感。

D

研发组件 · Custom Development

5 项
D1

自动创建评论插件

自研评论自动化插件，支持按规则批量生成产品评论，丰富产品页内容，缩短新品冷启动周期。

D2

产品筛选插件

自研后台可视化筛选配置插件，支持按产品分类、属性、标签、价格、库存等多维度自定义前台筛选条件，运营可独立配置无需技术介入。

D3

印名印号插件（WordPress 版）

基于 WordPress 框架自研原 Shopify 同等能力的印名印号插件，覆盖前端定制输入、价格联动、订单数据传递的完整链路，满足球衣类定制下单需求。

D4

Klaviyo 对接组件

研发与 Klaviyo 邮件营销平台的对接组件，实现用户行为数据、订单数据等关键节点向 Klaviyo 同步，支撑后续精准化的邮件触达策略。

D5

订单自动同步至 ttmall

研发订单同步链路，将站点订单实时自动同步至 ttmall 后台，避免人工导出/导入操作，保障订单履约链路的稳定与实时性。

04 / AI Capability

把 AI 嵌入运营，而不只是写在 PPT 上。

★ HIGHLIGHT

非技术同事，可以直接用自然语言管理网站。

本阶段的两项 AI 能力建设——MCP 服务器与产品组合 Skill——是项目的关键差异化产出。 它们使原本需要技术介入或大量手工操作的运营任务，现在可由 AI 自动完成。

Capability A · MCP Server

瑞典站 MCP 服务器

为瑞典站 WordPress 搭建 Model Context Protocol 服务器，对接 AI 助手。 运营、内容编辑可通过自然语言完成产品查询、内容更新、批量调整等后台操作， 技术门槛被大幅降低，重复性工作交由 AI 处理。

Capability B · Skill

产品组合自动生成 Skill

专用 Skill 可自动遍历整站产品，按既定规则智能生成产品组合方案， 直接输出为 Excel 文件。配合任务 10 的导入模块， 原本运营需要数小时手工筛选配对的工作，AI 几分钟即可完成。

闭环路径：
AI 生成组合（Skill）  →  输出 Excel  →  一键导入（任务 10）  →  上线
05 / Value Delivered

这 19 天带来了什么。

Infrastructure
荷兰新服务器上线，瑞典用户页面平均加载时间由 6.3 秒降至 2.9 秒（降幅约 54%），访问体验与稳定性显著改善，为旺季流量承接奠定基础。
Functionality
WordPress 站点已具备印名印号、心愿单、粘性购物车、产品组合导入等核心能力，与原 Shopify 站点功能对齐，具备独立承接业务的能力。
User Experience
购物车、结账、产品详情页、移动端导航等核心转化链路完成系统性优化，整站视觉风格统一，预期对转化率与复购率均有正向贡献。
Operation Efficiency
产品组合批量导入、后台自定义筛选条件等功能上线后，运营同事可独立完成大量原本需要技术介入的配置工作。
Payment
新增支付通道扩充了欧洲用户的支付选择，有利于降低弃单率。
AI Enablement
通过 MCP 服务器与产品组合 Skill，公司在 AI 与电商的结合上迈出实质性一步。这不仅当下提升了协作效率，也为后续把 AI 进一步嵌入运营、客服、内容生产等环节积累了可复用的能力底座。
